# Motif search

Search canonical poly(A) signals at the upstream of poly(A) sites.

## Usage

``` r
Motif.Search(Sites, fasta)
```

## Arguments

- Sites:

  A data.frame containing the information of poly(A) sites.

- fasta:

  A string specifies the location and name of genome file in FASTA
  format.

## Value

A list containing the types and genomic locations of signals.
