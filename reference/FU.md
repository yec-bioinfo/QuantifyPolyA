# Calculate the Pearson correlation coefficient of two PAC vectors.

Calculate the Pearson correlation coefficient of two PAC vectors.

## Usage

``` r
FU(s1, s2, score)
```

## Arguments

- s1:

  A numeric vector of PAC usages of sample X.

- s2:

  A numeric vector of PAC usages of sample Y.

- score:

  A numeric vector containing the genomic coordinates of PACs.

## Value

A numeric value in a range of \[-1,1\].
